# Code Description

**`Code/make_table.R`**
- Creates a table displaying the distribution of bacterial pathogens among patients with viral infections.
- Saves the table as an `.rds` file and an `.html` file in the `Output/` folder.

**`Code/make_figure.R`**
- Creates a figure displaying the proportions of bacterial coinfections by viral pathogen.
- Saves the figure as an `.rds` file and a `.png` file in the `Output/` folder.

**`Code/render_report.R`**
- Renders the R Markdown file into an HTML report.

**`Report.Rmd`**
- Loads and displays the table and figure generated by the R scripts.
- Provides the introduction, objectives, and summary of the analysis.
